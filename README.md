
# FaceGuard AI

Sistema de detección de uso de cascos de seguridad y reconocimiento facial.

## Tecnologías
- Python 3.13
- OpenCV
- DeepFace
- TensorFlow
- Roboflow

## Instalación

1. Instalar Python 3.13.
2. Descargar el proyecto.
3. Crear un entorno virtual:

python -m venv .venv

4. Activar el entorno:

.venv\Scripts\activate

5. Instalar dependencias:

pip install -r requirements.txt

6. Crear un archivo .env y configurar:

ROBOFLOW_API_KEY=TU_CLAVE_DE_ROBOFLOW

7. Crear la carpeta de personas autorizadas y registrar las fotografías con autorización.

8. Ejecutar:

python main.py

Presionar Q para salir.
